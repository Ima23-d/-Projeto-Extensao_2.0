## 🎯 Sobre o Projeto

**DataInsight Acessível** é uma plataforma inteligente de análise e visualização de dados que combina **Business Intelligence + Inteligência Artificial + Acessibilidade** para transformar dados complexos em decisões estratégicas.

Projetada especialmente para **microempreendedores e profissionais**, a plataforma permite:

* 📊 Interpretar dados financeiros e operacionais
* 🤖 Receber insights automatizados com IA
* ♿ Acessar tudo de forma inclusiva e acessível

Nosso objetivo é **democratizar o acesso à análise de dados**, eliminando barreiras técnicas e físicas.

## ♿ Recursos de Acessibilidade

O DataInsight foi desenvolvido seguindo as diretrizes da **WCAG 2.1**, garantindo inclusão real:

* ⌨️ Navegação completa por teclado
* 🔊 Compatibilidade com leitores de tela (NVDA, JAWS, VoiceOver)
* 🖐️ Integração com VLibras
* 🎨 Alto contraste e paleta acessível
* 🔍 Zoom sem perda de conteúdo
* 📝 Textos alternativos em todos os elementos visuais
* 🔔 Feedback sonoro e visual de ações
